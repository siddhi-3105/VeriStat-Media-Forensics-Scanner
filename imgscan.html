Check a photo or video before you trust it.

Veristat runs a still image or short video through a set of forensic checks — compression fingerprints, frequency artifacts, and metadata consistency — and returns a plain-language read on how likely it is to be manipulated or AI-generated.

This build is a working interface prototype. The scoring below runs a deterministic heuristic locally in your browser, not a trained detection model — see the note at the bottom for what a production version would need.

About this prototype — real deepfake detection needs a model trained on paired real/manipulated footage (frame-level CNNs, temporal consistency networks, or frequency-domain classifiers), continuously retrained as generation methods improve.
