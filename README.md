# 🔍 VeriStat – Media Forensics Scanner

### 📌 About the Project
VeriStat is a browser-based media forensics scanner designed to analyze images and videos for potential manipulation indicators.

### 🎯 Objectives
- Analyze uploaded media files.
- Identify potential image manipulation signals.
- Generate a risk score.
- Display scan results through a user-friendly interface.

### ⚙️ Features
- Image scanning (JPG, PNG, WEBP).
- Video scanning (MP4).
- Heuristic-based analysis.
- Risk score visualization.
- Browser-based interface.

### 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Python (if applicable)
